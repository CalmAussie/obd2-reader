# Trouble code support by car

Which cars in OBD2 Reader's car list get trouble codes explained, and how. This page is generated from the app's own car list and code library, so it always matches the current version.

## The two kinds of code

- **Generic codes** (P0, P2, P34, U0 and U3) mean the same thing on every car. The app explains 2,863 of them, with how urgent each is, common causes and what to check. They work on every petrol, diesel and hybrid car in the list, as long as its engine computer supports standard OBD2: cars sold in the US from 1996 (and a few from 1994), and elsewhere most petrol cars from about 2001 and diesels from about 2004, depending on the country.
- **Manufacturer-specific codes** (such as P1 codes) mean different things on different cars. The app only explains one where the maker's own published documents give the definition and say which cars and model years it covers, and only when your chosen car is one of them. Every other manufacturer-specific code is shown with the maker's name and where to look it up.

Fully electric cars have no engine computer, so they report few or no standard trouble codes.
